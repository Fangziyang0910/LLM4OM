示例与公开题库

从内置示例开始，了解公开题面的范围与来源。

本页内容

首页示例用于熟悉操作，公开题库用于浏览不同问题的表述和模型结构。选择题面后可以直接带入编辑区，再按自己的配置运行。

三种入门任务#

案例决策可尝试的变化
生产计划每种产品生产多少修改工时与最低订单
员工排班哪个人在哪天工作修改可用性与覆盖人数
配送指派哪辆车服务哪家门店关闭一条路线或改变费用

官网首页可操作这三个固定案例。Docs 的快速开始提供完整生产题面、录屏和附件，OR-Tools提供排班代码，CPMpy提供指派代码。

可下载的生产数据#

下载 production.json 或 production.csv，在题面说明产品、工时单位和资源容量，然后选择方法运行。

根据附件决定A、B的非负整数产量，最大化利润。
每种资源容量为8小时，工时数据的单位为小时/件。
JSON的usage按资源行、产品列排列。

公开题库目录#

“示例题库”包含9组、2033条题面：

题库数量题库数量
NL4Opt205IndustryOR99
NL4LP178ComplexOR18
MAMO Easy642OptiBench403
MAMO Complex210OptMATH128
NL4COP150

题面采用 OPT-Agent 的整理版本，来源与许可保存在题库来源说明。

怎样使用一条题目#

打开题库，选择分组和题面，阅读后带入输入区。根据变量域、约束和目标选择方法与求解器，再运行。完成后可用标签记录来源，并导出模型、代码和结果。

如果要比较方法，可选一条结构清楚的题，固定附件与预设，在方法对比中并排运行。需要额外数据的题目，可先在需求助手中补充字段与单位。

保存自己的案例#

将业务数据整理成附件，用备注记录字段含义和采用条件，再为运行添加标签。相同任务的后续变更通过调整条件和场景比较关联起来，逐步形成团队可复用的案例库。
