查看与导出结果

核对实际决策、数学模型和求解状态，导出完整方案。

本页内容
阅读实际决策根据状态判断结果导出哪种文件继续使用方案

运行结束后，先阅读求解状态、目标值和具体安排，再检查数学模型是否表达了原问题。结果页保留模型、代码、问题、数据和建模过程。

阅读实际决策#

“方案解读”用业务名称和单位解释变量；表格数值直接来自求解结果，大模型负责文字标签与说明。解读最多读取 100 个非零变量，全零解读取前 100 个；完整变量仍可展开、搜索和导出。

二维变量可以按矩阵查看。数学模型和代码若在方法中被修改，可以查看版本并与前一版比较。解读调用失败时，已有求解结果仍保留。

根据状态判断结果#

状态或情况怎样阅读
最优当前模型已有最优性结论，继续核对模型与题意
可行、超时但有解可以检查实际解；尚无完整最优性证明
局部最优按局部结论使用，见CasADi
不可行查看无解与冲突，不能当作执行方案
方法验证未通过阅读失败阶段和反馈，即使求解器有结果也需核对

如果新版代码尚未执行就失败，页面不会把上一版结果当作新版结果；旧结果可在过程步骤中查看。

导出哪种文件#

  • Excel：“求解方案”保存业务名称、全部变量值和单位；“问题与条件”保存题面、调整要求、附件名称、运行设置和链接。包含零值，不受页面展示范围限制。
  • CSV：下载完整变量数值，用于后续计算或核对。
  • Markdown 报告：问题、设置、结果、模型、代码和备注；非零变量最多列 500 个，并注明范围。

最优、可行、局部最优及超时但有实际解的结果可以导出 Excel。不可行、无界和执行失败不作为执行方案导出。导出是结果快照，修改 Excel 不会重新求解。

继续使用方案#

结果下方提供“讨论方案”“调整条件”和“业务场景对比”。先解释已有结果，再明确指定需要改变的要求，可以保留清楚的计算基准。
