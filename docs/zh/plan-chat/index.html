讨论与核对方案

询问方案含义、计算费用与余量，或从当前方案继续建模。

本页内容

在结果页点击“讨论方案”，可以围绕这次运行的问题、模型和实际数值继续提问。助手读取固定结果；普通解释不会重新求解。

可以怎样提问#

解释每个仓库的配送数量。
哪项资源限制了继续增加产量？请指出模型中的依据。
用当前方案计算总运费和剩余库存。

费用合计、资源余量和比例等计算可以直接使用实际决策值。“计算核对”卡片显示实际结果，展开可查看表达式和读取的变量数量。这个工具可读取超过方案文字解读范围的完整变量。

需要新方案时#

明确给出新要求，例如“预算提高到 1200，其他条件不变，请重新计算”。助手继承基准方案的方法、模型预设、建模库、后端和附件，整理新题面并重新执行完整流程。

对话回复使用的预设可以单独选择；它不会因此改写基准方案保存的建模配置。每个新方案独立保存，可以打开完整运行页核对或导出。

当前方案与历史方案#

助手标出“当前讨论方案”。查看历史只改变你正在看的内容，不改变后续计算的基准。要切换基准，明确说“回到原方案”或指定另一个方案。

一次只生成一个新方案时，它成为当前方案。一次比较多个场景时，各场景从同一基准出发，当前方案保持不变。

停止、刷新与重试#

Enter 发送，Shift+Enter 换行；可以停止或重试。刷新后可继续对话。最终回复失败时，已保存的计算结果仍可打开，重试会读取已完成方案。删除对话不会删除这些独立运行。
