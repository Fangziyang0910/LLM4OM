# Triage labels

| Canonical role | Repository label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | 维护者评估请求 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 agent |
| `ready-for-human` | `ready-for-human` | 需要人处理 |
| `wontfix` | `wontfix` | 不执行该请求 |

完成 triage 的 issue 恰有一个状态标签和一个类别标签：`bug` 或 `enhancement`。角色迁移按 triage 技能进行；先检查现有 labels，再按映射使用，保持一个状态。

triage 产生的 issue 或评论以该技能要求的声明开头：

```markdown
> *This was generated by AI during triage.*
```

其他任务的报告保留其实际来源，不标成 triage 输出。本文件是角色映射，不代表远端标签已创建或核验。
