# 验收场景与需求追踪

本页定义可观察验收结果，保留 AC 编号与 FR/NFR 映射。它不记录逐次完成状态。测试方法见[测试指南](development/testing.md)，已有证据见[支持验证](development/validation.md)。

当前交付范围是本机后端与单用户 Web。文档检查、确定性流程、真实求解和真实 LLM 分别提供证据。公开部署、多平台和正式发布不作为当前修改的前置条件。

## 独立数学依据

生产问题与反例见[手算参考](../examples/README.md#数学问题)。MILP 目标为 13，LP 松弛为 40/3；交换利润后的模型可以自报 13，但原问题目标为 12。

回归还需覆盖目标/约束常数、域与界、多解、无解、无界、时间限制、漏约束和目标偶合。Formulation 错误与 Code 错误分别观察，不能以求解成功替代语义证据。

## 交付记录

每次交付说明需求/AC、实际检查、环境和未验证条件。插件来源、执行身份和实际模型需要与证据一致。缺少外部条件保留原因，不计为已验证支持。正式发布只声明实际覆盖的能力。
