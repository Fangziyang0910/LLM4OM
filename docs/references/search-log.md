# 资料核验说明

研究资料主要依据 2026-10-08 的定向检索，后续固定源码和数据观察分别保存。本页说明纳入规则、身份更正和读取边界，不维护逐次请求日志。

## 来源与读取范围

采用作者论文、官方出版记录、作者仓库和官方接口文档。二手资料只用于发现线索。平台、推理、训练、表示、数据绑定、评测和交互分别归类。

书目与阅读范围在 [catalog.json](catalog.json) 维护，[资料页](README.md)和 BibTeX 由工具生成。摘要、选读章节和源码观察分别标识，未取得全文时不补写全文结论。

这是代表性调研，不是穷尽系统综述。它支持机制比较与平台设计，不替代作者实验复现或完整数据审计。

## 身份核验

- arXiv ID 与论文标题逐项核对，预印本和正式记录合并在同一条目。
- 同名 OptiBench 按来源区分。误链接到无关手语论文的 ID 未纳入。
- OpenReview 未能核验的作者或接受状态保持未知。
- OptiMUS 论文 revision、代码分支和数据 release 分别固定。
- ORPilot 的固定代码默认直接生成，IR 为按需节点；没有将其概括为强制 IR 流程。
- NLP4LP 原始快照与 OPT-Agent 中名为 NL4LP 的整理题库分别标识。

## 使用这些证据

论文的效果属于其具体模型、样本和预算。不同论文数字不直接拼成排行榜。源码提供的流程也不自动证明其每条分支可用。

接入时保存实际来源、版本、许可、公开输入和私有参考边界。平台的当前方法是明确变体；实际支持与验证见[方法说明](../development/methods.md)和[支持验证](../development/validation.md)。
