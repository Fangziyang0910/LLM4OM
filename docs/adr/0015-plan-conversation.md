# 方案对话按固定方案读取事实，明确变更交回平台图

方案对话独立于建模方法，引用原生线程的固定检查点。LangChain Agent 读取实际模型与结果；用户明确修改条件时，工具执行原方法的平台图，再把完整结果保存为独立原生线程。单个新方案成为后续对话的当前方案；多个场景从同一个基准计算，不自动选择其中一个。此边界不改变研究方法，也不把 LLM 预测当作求解结果。

工具在当前原生对话 Run 内执行平台图，不向同一服务器的任务队列提交子 Run 后等待。后者在只有一个执行槽、或全部执行槽都在等待子任务时会死锁。进程内图关闭检查点继承和消息推送，完成后用原生 `threads.create(supersteps)` 保存完整步骤、配置和结果。派生方案有独立检查点与完成时间，没有单独的排队 Run；运行页据实际完成时间显示已完成。取消由父 Run 传递到模型和沙箱，未完成的计算不保存为已完成方案。

原方案和附件不改写。已保存的新方案在最终文字回复失败或对话删除后仍可打开；失败后重试读取本轮已算好的结果，不再重复计算。所有记录继续使用 LangGraph 的线程、检查点和删除流程，不增加业务数据库或任务队列。
