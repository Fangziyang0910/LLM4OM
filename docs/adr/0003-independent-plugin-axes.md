# 方法、LLM、建模语言与求解器独立配置

平台把建模策略、语言模型调用、模型构建和数值求解定义为独立接口，由能力规划建立兼容路径。若把它们封进单一端到端插件，接入初期更简单但方法比较、模型替换与后端互换会持续依赖特例；独立配置的代价是必须定义能力、数据与失败契约，不能假定所有组合均可用。

2026-10-14明确采用策略集成：保留研究方法的编排和核心阶段提示，代码目标由所选Backend／Solver组合，求解调用由平台执行。Backend在已有Manifest中声明代码生成要求，Context提供已预检的目标；方法不按求解器ID编写分支，也不依赖原论文的代码API。当前复用Pyomo通道连接三个Solver，同时保留可选gurobipy通道。
