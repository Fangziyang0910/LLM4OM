# 运行只选择预设模型，密钥不离开服务器

## 背景

工作台要部署在公网服务器上，供课题组成员直接访问，不做登录。[0009](0009-langgraph-server.md) 的运行上下文写服务商名和模型名，设置按服务商保存，页面可以修改设置，模型列表接口在密钥留空时补入已保存的密钥。

这在只监听 `127.0.0.1` 时安全。开放端口后，任何访问者都能读到密钥预览、改写已保存的设置，或者让服务器把已保存的密钥发往自己指定的地址。

## 决定

- 运行只选择**预设模型**。预设固定服务商、接口地址、密钥、模型 ID 和请求参数。运行上下文只写预设 id，不能改模型。
- 预设只能添加和删除，没有修改操作。同一模型可以添加多个预设，id 由模型名生成并去重。
- 任何接口都不返回密钥，也不返回掩码。模型列表接口只使用请求中填写的密钥。密钥只发给与它一起保存的接口地址。
- 服务器 `LLM4OM_LLM_*` 变量给出的预设（id `env`）排在第一位，是默认预设，页面上不能删除。
- `llm4om serve` 默认监听 `0.0.0.0`。
- v0.38 的 `llm-settings.json` 在首次读取时转换为预设。

## 取舍

- 没有登录：访问者可以消耗预设的额度，添加和删除页面上添加的预设，删除运行记录。部署者用防火墙或反向代理限制访问范围。服务器预设不能从页面删除，保证总有一个可用的默认预设。
- 访问者添加预设时可以填写任意接口地址，服务器会向该地址发请求。这不泄露已保存的密钥，但服务器可以被用来访问它能到达的地址；公网部署时不应把服务器放在可信内网中。
- 运行不能临时改模型。要换模型或参数，添加新的预设。
