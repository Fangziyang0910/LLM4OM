# 通用 LLM 配置与页面密钥

2026-10-14，SDK／Worker 0.37.0 开发版本。规范由 [FR-05／FR-15](../requirements/v1.0.md)和[插件契约](../plugin-contracts.md)维护。

LLM Provider 与具体模型独立配置，建模方法和求解器复用同一模型调用接口。Web 显示接口协议、API Base URL、模型名称和 API Key。模型名称由使用者自由填写；服务使用现有 OpenAI 兼容或 Anthropic 协议，已安装且声明 `http_text/0.1.0` 的 Provider 也可选择。不按模型名字新增 Adapter，不引入提供方 SDK 或配置管理系统。

切换方法／求解器、浏览内置样例不改 LLM 设置。切换协议时仅替换已有内置默认 URL，自定义地址和模型名保留。原 `.env` 默认服务仍可使用；更换协议或地址后，需提供对应服务的 Key，不能自动把默认服务的密钥转发给新地址。普通兼容性检查不要求网络或 Key；显式目录检查和运行使用填写的 Key。

页面 Key 位于密码输入框，通过 `X-LLM4OM-Provider-Key` 请求头独立提交给本机后端。公开 JSON 仍由原隐私契约校验，不允许内嵌 `api_key`。后端按工作项保留内存密钥，公开配置只有 `credential_env` 引用；拥有的 CLI 应用进程获得私有环境覆盖，不修改全局 `os.environ`。复用原 Provider／Gateway 的认证、目录检查、预算、取消和响应脱敏。方法输入、生成代码容器、工作区文件和导出不包含 Key。

Key 不写入 `.env`、浏览器存储或公开产物；关闭页面会清空输入框，重启服务会清空服务内存。已有页面密钥运行可在结果页“运行密钥”中重新填写，再恢复、派生重跑或修订；已保存配置与父运行不改写。原来使用服务端环境的工作项继续使用原凭据来源。

验收入口：

- `tests/test_web_llm_settings.py`：两个确定性 HTTP 协议、各自模型与私有 Key、目录检查、实际 HiGHS 目标 13、运行与导出无 Key、服务重启后重新供给 Key 派生求解、拒绝公开 Key 与默认密钥跨服务复用。
- `tests/web_llm_settings_flow.cjs`：可见表单、协议默认地址、自定义模型／地址、方法与求解器独立选择、请求头与 JSON 分离、结果页密钥重填、无浏览器存储与窄屏。
- 相关 Web 回归、前端类型／构建、Python 类型、仓库检查和安装包静态资源检查。本机服务与 Worker 更新后保持历史工作区内容。

工程 HTTP fixture 不代表各供应商真实模型验收；本轮没有使用外部供应商密钥新增付费调用。
