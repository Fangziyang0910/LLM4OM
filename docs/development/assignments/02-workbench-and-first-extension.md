## 交付目标

## 具体任务

1. 复跑 A 的关键用例。沿 [Composer.tsx](../../../frontend/src/components/Composer.tsx)、[RunView.tsx](../../../frontend/src/components/RunView.tsx) 和 [useRun.ts](../../../frontend/src/useRun.ts) 完善输入、过程和结果阅读。统一对齐、间距、按钮、表单和弹窗，复用现有 React、Radix 与样式，不另换框架。
2. 核对配置保存、方法和语言切换、重复提交、迟到响应、取消、失败、断流重新连接、历史和下载。步骤、数学模型、代码和结果必须属于同一次运行。当前未提供通用澄清和人工派生编辑，本阶段不要求恢复。
3. 依据 [LLMOPT 论文](https://arxiv.org/abs/2410.13213) 与[官方仓库](https://github.com/antgroup/LLMOPT)，固定源码版本，实现五元素表述、代码生成和执行反馈修正的核心流程。使用通用外部 LLM，不要求专用训练权重或完整论文复现，也不能只给已有方法改名。
4. 使用现有 `Method`、`ModelingState`、`Context` 和 LangGraph 节点实现方法。同步 `methods()`、服务端图注册、`langgraph.json`、支持语言、来源说明和测试。CLI、Web 选择、真实步骤、最终产物与下载必须一起接通。
5. 复用 A 的兼容矩阵和数学用例，补充 LLMOPT 在声明支持的每个语言及求解器绑定上的检查。原提示只针对 MILP 时，限制 `Method.languages`，不声称支持 CP。当前接口见[架构](../../architecture.md)，方法接入步骤见 [CONTRIBUTING](../../../CONTRIBUTING.md#接入研究方法)。
