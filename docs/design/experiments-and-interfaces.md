## DD-06 Benchmark 与实验展开

平台题库提供已集成公开题面。独立评测通过 TaskAdapter 导入固定数据，分开公开输入和私有参考，并在建模前冻结选择、资格和协议。

ExperimentSpec 展开任务、配置和独立 repeat。全部未排除组合预检后，逐样本调用单问题应用。每个样本使用独立状态与运行目录。

生成、执行、预算、取消和评测失败保留原资格分母。相同问题的重复不增加独立问题数。无 eligible 时指标为 null。指标规则由[评测协议](../evaluation.md)维护。

比较方法时固定公开输入、LLM、预算和可比执行条件。使用不同角色模型或专用训练模型的系统比较单独分组。对应 FR-08–12/18/28–34，AC-04/05/15–17/22。

## DD-07 持久化恢复与报告

先保存产物，再发布引用它的事件。事件以递增序号排序。固定路径是当前视图，不可变历史维持旧引用。存储核对大小、哈希、拥有者和写入意图。

外部请求先记录身份与预留，响应落盘后结算。私有资源链和核心锚点共同验证恢复窗口。成功响应复用，未知结果保留预留且不自动重发。

核心阶段和方法内部状态分开保存。完整阶段/执行可由发布收据恢复；未完成推理需要方法检查点。身份不兼容拒绝，显式 rerun 创建派生运行并继承消耗。

报告读取已保存公开结果，不重新选择或评分。Reporter 失败单独记录，可在固定身份下重试。缓存命中、回放和新的独立运行分别呈现。对应 FR-17/26/30–34，AC-08/17–19/21/22。

## DD-08 CLI 与 Web 共用应用接口

CLI、Web 和 SDK 调用共同的预检、run、resume、edit、benchmark 和 report 用例。Web 后台通过独立应用进程运行，可信插件不在多个任务间共享解释器。

页面主线是问题输入、模型与求解器选择、建模过程和结果。内置题库只填入公开输入；批量实验使用 CLI，已有 HTTP 实验接口继续复用同一用例。

当前选中版本共同绑定数学模型、代码、结果、导出和编辑模板。晚到响应不能覆盖新选择。历史浏览不恢复或改写运行；取消和恢复仍操作当前后台任务。

相同配置在各入口遵守相同 fingerprint 规则，每次新运行仍有独立 ID。页面轮询读取真实事件，不另建推测进度状态机。对应 FR-06/20/24/26/34–36，AC-20/23。
