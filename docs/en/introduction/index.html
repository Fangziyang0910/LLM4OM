LLM4OM documentation

From your first optimization problem to methods, solvers and deployment.

LLM4OM turns natural-language problems and data into optimization models and calls solvers to compute plans. Describe requirements, inspect decisions and the modeling process, then revise conditions, compare alternatives and export results.

Choose an entry point#

EntryStarting pointNext actions
Optimization chatSend a problem or ideaClarify, compute, query, revise and compare scenarios
Manual modelingA prepared statement and dataEdit inputs, choose settings and follow execution
Requirements assistantA developing business ideaCreate an editable statement and attachments

First-time users can complete the production quickstart. To run a service, see installation.

From requirements to a usable plan#

A run retains statement, attachments, configuration, formulation, code, values and steps. Original and revised plans remain connected to their inputs.

Everyday features#

TaskGuide
Add tables and edit fields or valuesUpload and edit data
Read production, staffing or allocation decisionsResults and exports
Query a decision or total costsDiscuss a plan
Change a requirement and compute another planRevisions
Compare budgets, demand or resourcesScenarios
Find past tasks and record decisionsHistory, tags and reports

Understand modeling and computation#

Methods covers 13 workflows with mechanisms, Mermaid diagrams, step-by-step examples and current parameters: generation, feedback repair, layered validation, type retrieval, component search and data binding.

Libraries and solvers covers nine libraries, native interfaces, backends and complete code. Production, staffing, assignment, convex quadratic and nonlinear examples help select a computation path.

Watch and interact#

Docs include localized workbench recordings, screenshots and interactive examples. Download quickstart data, step through method artifacts, or change solver-example parameters and inspect computed results.

The interface supports Chinese, English and light/dark/system themes. Desktop dividers resize work areas; narrow screens use tabs for main content and assistants.

Teams and scripts#

Team deployment covers shared services, HTTPS and access configuration. Usage and backups covers quotas, concurrency and data maintenance. CLI and Python runs the same modeling workflows from existing programs.

LLM4OM is developed by the EIPI team, with publicly maintained source and documentation.
