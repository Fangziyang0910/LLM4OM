Chat Agent 的界面入口叫“优化对话”，位于侧栏。它把需求沟通、实际建模、结果讨论和条件调整放在同一段持续对话中。

## 从一句话开始

你可以直接发送完整问题，也可以先讨论一个想法。普通知识问答、文字修改、代码解释和算术不会自动启动优化建模。确实要计算方案时，说明要决定什么、目标是什么，以及必须满足的要求；有数据就添加附件。

```text
请根据附件安排下周排班。
每天至少 3 人，每人最多工作 5 天。
周末必须有一名主管，目标是总用工成本最低。
```

信息不足时，助手会追问影响下一步的内容。问题明确后，它调用完整建模流程，生成数学模型、代码并实际求解。

## 观察计算与结果

对话显示实际的计算阶段和方案入口。电脑端可以在旁边的建模工作区查看过程、数学模型、代码和结果，再打开完整运行页导出 Excel。分隔线可拖动，也可用 Tab 聚焦后按方向键调整。

默认配置是 Direct、Pyomo、AUTO。可以在消息中指定方法、建模库和后端，也可以用输入框旁的“建模偏好”固定方法与建模库。例如：“用 BIND 读取这份 JSON，并用 Pyomo 建模。”

## 继续提问或改变条件

| 你的消息 | 平台的操作 |
|---|---|
| “为什么周二安排了这两个人？” | 读取已有模型与结果，解释方案 |
| “计算这份方案的周末费用合计。” | 使用实际决策值计算，不必重新求解 |
| “周二至少 4 人，其他不变，请重新计算。” | 从当前方案生成新问题，重新建模求解 |
| “分别算预算 1000 和 1200 的方案。” | 从同一基准计算多个场景 |

一次新方案成为后续讨论的当前方案。要指定基准，可以说“回到原方案，先不重算”或“接下来使用第二个方案”。仅在界面浏览历史方案不会切换计算基准。

## 数据、搜索与恢复

点击附件可检查和编辑。修改附件影响后续新建模型；要使用新数据，请明确要求重新建模，已有方案的数据仍固定保存。

需要公开资料时，可开启联网搜索并展开来源。资料中的业务建议经过你确认后再用于计算。DeepSeek 的深度思考开关控制本轮对话，工具调用中的建模仍使用运行预设。

Enter 发送，Shift+Enter 换行。可以停止和重试；刷新会重新连接活动运行。文字回复失败时，已经保存的计算方案仍可打开。删除对话不会删除独立保存的方案。
