Chat Agent 是工作台的默认首页（`/`）。打开即可直接用大白话描述优化需求、拖入 Excel/CSV/JSON 表格，系统会自动在精确求解器与 AutoCO 智能优化引擎间选配，并在右侧实时展示方案、交互式 Pareto 权衡图与数学模型。

## 从第一条消息开始

直接输入要解决的问题即可，默认处于「自动求解」模式：一般线性/整数/凸优化问题自动走精确求解，多目标权衡、大规模组合调度或启发式需求则自动路由到 [AutoCO](../autoco/)。如果你希望体验特定方法，点击输入框底部的策略按钮即可随时指定 9 种策略中的任意一种以及底层建模库与求解器。

```text
我们要安排下周的门店排班。每天至少3人，每人最多工作5天。
周末每个班次都要有主管。请先根据附件检查还缺哪些信息，
确认后计算用工成本最低的安排。
```

助手根据当前信息组织回复，工具执行时显示建模阶段与方案卡片。电脑端旁边的工作区可查看模型、代码和结果；点击方案入口可打开完整运行页并导出。

```mermaid
  Decide -->|查询已有方案| Query["读取变量与计算合计"]
  Decide -->|修改业务条件| Revise["从当前方案生成新运行"]
  Decide -->|比较多个条件| Scenarios["固定基准批量计算"]
  Decide -->|选择讨论基准| Select["切换到已保存方案"]
  Model --> Saved["保存方案，继续对话"]
  Revise --> Saved
  Scenarios --> Saved
  Query --> Saved
  Select --> Saved
```

下面从利润13的生产方案开始，可以依次查询资源使用、增加最低产量、比较场景、回到原方案。每个按钮对应一种对话操作。


在真实工作台中，可以直接发送这些消息：

| 想做什么 | 消息示例 | 得到什么 |
|---|---|---|
| 查看具体决策 | “列出周二上班的员工及其费用。” | 从保存结果查询变量 |
| 算派生指标 | “合计这份方案的周末成本。” | 计算卡片、表达式与实际值 |
| 调整一个条件 | “周二至少4人，其他不变，重新计算。” | 新方案与完整运行记录 |
| 同时比较条件 | “分别计算预算1000和1200的方案。” | 共同基准下的多个场景 |
| 选择后续基准 | “接下来使用第二个方案。” | 当前讨论方案选择回执 |

## Agent 使用哪些工具

| 工具 | 在对话中的作用 |
|---|---|
| `modeling_capabilities` | 查询当前方法、问题范围、建模库与实际后端可用状态 |
| `model_and_solve` | 把明确问题交给完整建模方法，保存新运行 |
| `solve_scenarios` | 从固定方案整理并计算多个变更场景 |
| `lookup_variables` | 按名称、分组和分页读取完整变量值 |
| `calculate` | 使用已读取数值计算费用、比例或资源合计 |
| `select_plan` | 将已保存方案选为后续对话基准 |

一次对话轮次通过一个方案变更工具推进计算；多个明确条件可通过场景工具一并提交。变量查询和数值计算可配合使用。

## 当前方案、浏览与附件

一次新增方案完成后，它成为后续讨论的当前方案。多个场景从同一基准分别计算，当前基准保持原选择。工作区标明“当前讨论方案”和“正在查看历史方案”，可随时返回讨论中的方案。

附件点击文件名即可编辑。保存后，在消息中要求按新数据重新建模；新运行保存新附件，已有方案保留原输入快照。联网搜索开启后可展开来源，确认采用的业务规则后继续计算。

优化对话在附件读取或保存完成后才允许发送消息，等待期间可以继续编辑文字。保存失败时保留原附件并显示错误，恢复后可重新添加同一文件。

## 日常操作与恢复

Enter 发送，Shift+Enter 换行。桌面端左侧边栏支持一键折叠与展开，中间分隔线支持拖动或按键盘方向键调整对话与右侧方案面板宽度。上翻阅读时自动暂停跟随，点击“回到最新消息”即可恢复。

刷新会连接服务器上的活动运行。已保存的方案可从对话卡片或侧栏历史记录直接打开；停止与重试入口保留本轮上下文。DeepSeek 的“深度思考”开关控制当前对话回复，工具中的建模使用运行预设参数。
