在结果页点击“讨论方案”，可以围绕这次运行查询决策、计算指标、解释模型，或继续生成新方案。结果与助手并排显示，便于边问边看。

## 先问一条具体问题

```text
列出周二被安排的员工与各自费用。
合计原方案的周末成本，并给出计算表达式。
查找产品B的产量，以及对应的资源使用。
```

助手读取当前讨论方案的题面、模型和保存结果。查询变量可以按名称和分组分页读取完整值，适合需要定位单个决策或汇总较多变量时使用。

## 查询与计算怎样衔接

```mermaid
flowchart LR
  Question["关于当前方案的提问"] --> Values["查询相关变量"]
  Values --> Calculate["计算费用、比例或合计"]
  Calculate --> Card["展示表达式与计算结果"]
  Card --> Continue["继续解释或调整条件"]
```

“计算核对”卡片显示实际结果，展开可看表达式和读取的变量数量。普通算术也可直接提问。结果旁边的模型与原始变量能帮助理解计算使用的具体分量。

## 用一句话建立新方案

```text
B 至少生产3件，其他条件保持不变，请重新计算。
分别计算 B 至少3件和至少4件两个场景。
回到原方案，接下来把切割容量改成10小时。
```

一次新方案成为当前讨论方案，多个场景从同一基准分别计算。对话中显示题面整理、建模、求解与解读阶段，完成后可以打开计算方案，或对比本轮结果。

## 当前讨论方案与相关方案

助手顶部标出当前方案。“相关方案”中可浏览原运行或其他方案，主区域显示所选结果。明确说“接下来使用第二个方案”会收到选择回执，后续计算采用该方案。

建模继承基准方案的方法、模型预设、库、后端和附件。对话回复使用的预设可以单独选择，这两个配置在各自位置保留。

## 保存与日常操作

拖动分隔线分配结果与对话宽度，刷新后保留布局。向上阅读暂停跟随，点击“回到最新消息”继续。停止和重试入口可恢复本轮讨论，已保存计算方案始终可从卡片和历史打开。
