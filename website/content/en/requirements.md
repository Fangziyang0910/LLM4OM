Requirements chat helps when you do not yet have a complete problem statement. It organizes goals, rules, data and open questions into a draft you can edit.

## Open it and describe the idea

On the manual modeling home page, choose Prepare requirements through chat. Existing text and attachments are carried over, or you can start empty. Describe the decision first: “I need to allocate inventory across three warehouses, but I am unsure what data to prepare.”

The assistant updates the draft and asks about information that matters to the problem. The main editor keeps the draft visible, with the assistant beside it on desktop and a tab switch on smaller screens.

## Review and edit the draft

Edit quantities, units, indices and mandatory requirements directly. Manual edits save when you leave the editor, or through Save draft. Pending edits are saved before the next message or modeling handoff.

Inspect and edit attachments as needed. Web search can help find public information; expand and check its sources. Confirm suggested rules before treating them as fixed requirements.

## Hand it to a modeling method

Once the draft is ready, select the run configuration and click Start modeling. You can also choose Use for modeling to adopt the draft and close the assistant. The method receives the problem text and attachments, rather than the conversation itself.

The requirements assistant does not start solving on its own. Review unresolved questions before handoff so tentative requirements are not mistaken for confirmed ones.

## How it differs from Optimization chat

[Optimization chat](../chat-agent/) can call modeling tools, save plans and revise them within a conversation. Requirements chat focuses on an editable problem statement for users who want to review it before starting a run. Resume the conversation from history; deleting it does not delete modeling runs already created from it.
