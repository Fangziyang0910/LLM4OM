History connects requirement drafts, modeling runs, revisions and comparisons. Tags and notes capture decisions; fixed links and reports support team discussion and archiving.

## Find related task records

The sidebar groups requirement conversations, original runs, revisions and comparisons by recorded source. Expand related records to follow a task from draft to alternative plans.

History loads 100 items at a time. Load earlier runs to continue. Text and tag filters apply to loaded items, with the scope shown in the interface.

## Organize with tags and notes

Open “More → Notes and tags.” For a staffing task, add `store-staffing` and record the chosen scenario and next confirmation. Search `#store-staffing` in the sidebar.

| Information | Suggested record |
|---|---|
| Task category | Tags for production, staffing or transport |
| Decision | Note the chosen plan and reason |
| Next action | Record data or rules awaiting confirmation |
| Comparison | Retain the comparison link and related runs |

## Export and share

“More → Export report (Markdown)” saves the problem, settings, result, formulation, code and notes. Excel and CSV support complete numerical analysis; see [exports](../results/).

Run and comparison pages have fixed links for members using the same service. Links open the corresponding saved record for discussion of concrete inputs and models.

## Run again or edit

“Run again” uses the same statement and settings. “Edit and run” returns inputs to the editor. Select a current preset when executing again. Each new run is retained independently.

Deleting one record leaves other related runs. Original comparison checkpoints follow their original record; revised runs retain their own inputs and results.

## Persistence and team use

The service workspace retains history, presets and run state across normal restarts. Tags and notes form a shared case library. Administrators can back up the complete workspace using the [configuration guide](../configuration/).

Start a task with [requirements](../requirements/) or continue a saved one in [plan conversation](../plan-chat/).
