建模方法/LLMOPT

LLMOPT

构造五要素模型，再根据自我校正回到相应步骤。

本页内容
执行流程怎样使用流程与训练模型来源与平台适配当前参数

LLMOPT 先建立五要素数学模型，再生成代码。自我校正分别判断模型和代码，把修正送回对应步骤。

执行流程#

集合、参数、变量、目标、约束 → 代码 → 执行 → 自我校正
                  ↑ 模型有误       ↓ 代码有误
                  └── 重建模型     重写代码

模型判错时重新定义五要素，再生成代码；仅代码判错时回到代码生成。最后保留实际执行得到的结果，重解次数受预设限制。

怎样使用#

在运行设置选择 LLMOPT。它适合需要单独检查问题结构和代码映射的工作流。查看五个小节是否齐全，参数来自哪里，约束是否覆盖题面。

平台保留当前执行模型与其求解结果的对应关系；新版代码在执行前失败时，不会继承上一版的解。

流程与训练模型#

LLMOPT 研究包含微调与对齐得到的模型。平台接入的是测试时的五要素与自我校正流程，默认使用你选择的预设，不会自动下载论文模型。若要使用发布权重，需要自行提供兼容模型服务，再添加预设。

来源与平台适配#

提示来自 LLMOPT 固定提交，自我校正循环依据论文实现。上游未发布该循环代码，模型或代码判错后的路由记录在原始文档中。提示按所选库和平台代码契约适配，相关研究复现许可说明见项目 NOTICE。

当前参数#

参数来自部署时的方法预设，随每次运行记录保存。页面、命令行和 Python 接口均不提供单次运行的参数修改。
