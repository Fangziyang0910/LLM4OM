Getting started/Install and launch

Install and launch

Start the platform with Docker Compose or a local Python environment.

On this page
Prepare an environmentStart with Docker ComposeConfirm setup in the workbenchStart from PythonMaintenance commandsWebsite and platform addresses

If you already have a team service address, open it in a browser. To run your own service, Docker Compose installs the workbench, server and solver environment.

Prepare an environment#

SetupRequirementsUse
Docker ComposeDocker, Compose v2.24+, model-service configurationPersonal or team service
Python servicePython 3.11–3.13, uv, Docker, model-service configurationDevelopment or existing Python setup

Data lives in a workspace or Compose volume. Choose a machine with persistent storage and access to the model service.

Start with Docker Compose#

git clone https://github.com/Fangziyang0910/LLM4OM.git
cd LLM4OM
cp .env.example .env
chmod 600 .env

Edit .env with provider, endpoint, model ID and key; see LLM presets. Then run:

docker compose up -d --build
docker compose ps

After building, open http://localhost:8767. Initial setup downloads dependencies and builds the Worker. Inspect startup with docker compose logs -f app.

Confirm setup in the workbench#

Check the default preset and backend options. Complete the production quickstart; the run should retain quantities, formulation, code and stages.

Then add attachments or try Optimization chat. Other devices can use the server address. See team deployment for shared access and HTTPS.

Start from Python#

In the cloned repository:

uv sync --all-extras
uv run llm4om build-worker
uv run llm4om serve --workspace runs/web --port 8767

This uses bundled workbench build files and Docker solver sandboxes. runs/web retains history and presets; use --workspace for another location.

Maintenance commands#

ActionCommand
Statusdocker compose ps
Logsdocker compose logs -f app
Updategit pull, then docker compose up -d --build
Apply environment changesdocker compose up -d app
Stop, retaining data volumedocker compose down

See presets for connections, backends for solver setup and backups for persistent data.

Website and platform addresses#

GitHub Pages serves the website and Docs. The complete platform runs Python and solver services on the configured machine. Team members calculate through that deployed service address.
