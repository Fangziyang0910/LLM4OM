Modeling methods/AutoCO

AutoCO

12-family metaheuristic engine for large combinatorial, black-box nonlinear, and multi-objective Pareto problems.

On this page

AutoCO (Automated Combinatorial Optimization) is the platform's metaheuristic optimization engine. For large-scale combinatorial scheduling, black-box nonlinear objectives, or multi-objective trade-offs, AutoCO compiles plain-language descriptions into fast sandboxed NumPy problem evaluators, then combines a feature knowledge graph with live pilot trials to select and run the best configuration from 12 metaheuristic families.

When to choose AutoCO#

Problem characteristicsRecommended engineWhy
Multi-objective trade-offs (e.g., electricity cost vs. fault risk)AutoCO (NSGA-II / MOEA/D / NSGA-III)Produces a full non-dominated Pareto front and knee recommendation in one run without manual weights
Large quadratic assignment, routing, scheduling, or packing (e.g., QAP-30)AutoCO (SA / TS / ILS / LNS)Exact branch-and-bound frequently times out; high-throughput neighborhood search reaches near-optimal solutions in seconds
Black-box, piecewise, or nonconvex nonlinear objectivesAutoCO (CMA-ES / DE / PSO / GA)Evaluates evaluate(x) directly without Big-M linearization or convexity assumptions
Small-to-medium LP, MILP, or standard convex modelsExact Solvers (Direct / TriVAL)Reports feasibility, optimality and available conflict diagnostics

In the default Auto mode inside Chat Agent, the platform automatically routes multi-objective and metaheuristic requests to AutoCO while keeping exact models on exact solvers. You can also pin AutoCO explicitly in the composer or in Configure a run.

Workflow and worked example#

FOLLOW THE EXAMPLE
1. Semantic & 4-tuple model

Parses objectives, decision variable semantics, and hard constraints into a typed 4-tuple M = (P, X, F, C), explicitly classifying variables as permutation, assignment, binary, integer, or continuous.

Objectives: min total electricity cost f1(x), min total fault risk f2(x)
Decision variable: assignment[0..11] in {0, 1, 2, 3} (4 heterogeneous GPU clusters)
Hard constraints: cluster capacities [80, 90, 75, 85]; conflict pairs (0,1), (3,6), (5,10) separated
2. Compile & smoke test

Generates build_model(data) -> Problem with a vectorized NumPy evaluate(x) -> (objectives, violation) function and optional decode(x), then runs a sandbox smoke check to verify shapes, violation semantics, and throughput.

VarSpec(name='cluster', var_type='assignment', size=12, n_categories=4)
Smoke check passed: senses=['min','min'], 0.04 ms/eval, violation >= 0 verified
3. KG selection & pilot trial

The selection agent queries the Problem-Feature <-> Algorithm-Feature knowledge graph for bi-objective constrained assignment, inspects candidate operators, and benchmarks the top configurations in brief sandbox pilot trials.

Features: bi_objective, assignment, capacity, conflict
Pilot comparison: NSGA-II (repair-aware mutation) vs. MOEA/D
Selected: NSGA-II (100% feasible population, +4.8% hypervolume in pilot)
4. Sandbox solve & Pareto output

Executes the full search budget inside the network-isolated sandbox, extracts zero-violation non-dominated solutions into a Pareto front, highlights the Knee Point compromise, and decodes readable assignments.

Status: feasible · 200 non-dominated Pareto solutions
Lowest cost end: cost 272.5 · risk 18.49
Recommended Knee Point: cost 286.4 · risk 15.36
Lowest risk end: cost 300.1 · risk 12.14

Built-in 12-family metaheuristic pool#

The AutoCO sandbox ships with 12 engineered algorithm families grouped into three paradigms. The agent matches operators and constraint-handling strategies to each variable block (permutation, assignment, binary, integer, continuous, or mixed blocks):

ParadigmAlgorithmsTypical fit
Trajectory & local searchSA (Simulated Annealing), TS (Tabu Search), ILS (Iterated Local Search), LNS (Large Neighborhood Search)Quadratic assignment (QAP), large scheduling, capacity/time-window/conflict combinatorial optimization
Population & evolutionaryGA (Genetic Algorithm), CMA-ES, DE (Differential Evolution), PSO (Particle Swarm), ACO (Ant Colony)High-dimensional nonconvex continuous optimization, black-box tuning, mixed-integer and constructive routing
Multi-objective evolutionaryNSGA-II, MOEA/D, NSGA-IIIBi-objective and many-objective Pareto trade-offs (simultaneously balancing cost, risk, fairness, or latency)

Knowledge-graph reasoning and pilot verification#

Generic LLM prompts often default to a basic genetic algorithm regardless of problem structure. AutoCO grounds algorithm and operator selection in an explicit Problem-Feature to Algorithm-Feature knowledge graph (SUITS, CONFLICTS_WITH, SYNERGIZES_WITH):

  • For dense pairwise coupling (such as QAP), it avoids slow constructive rebuilds and favors high-turnover O(1) swap trajectories (SA, TS, ILS).
  • For precedence or conflict constraints, it avoids order-reversing moves and selects order-preserving relocations, ruin-and-recreate (LNS), or tabu memory.
  • For three or more objectives, it activates reference-direction niching (NSGA-III) to maintain balanced front coverage in higher dimensions.
  • When enable_pilot is enabled, the agent runs brief live sandbox trials on the top competing configurations before committing the full compute budget to the winner.

Verified benchmarks and reading Pareto fronts#

Under the same LLM and isolated sandbox environment, AutoCO complements exact mathematical programming:

BenchmarkExact baselinesAutoCO engine
30-Node Quadratic Assignment (QAP-30)Timed out (+6.2% to +10.7% gap)18s near-optimal (+0.29%, 1.32M evaluations)
Tri-Objective GPU Scheduling (36 jobs)Single scalarized point only200 zero-violation Pareto solutions (+11.5% HV)
Standard LP / MILP instancesProven global optimum in secondsBest served by exact mathematical solvers

When a multi-objective run finishes, the workbench renders an interactive Pareto front scatter plot and highlights the recommended Knee Point. Click any point on the chart or row in the solution table to inspect its decoded decisions, ask follow-up questions in chat, or export to Excel/CSV.

Usage notes and trade-offs#

AutoCO requires no commercial solver license and no algebraic modeling library choice. In Compare methods and LLMs, you can run AutoCO directly alongside Direct, TriVAL, and other methods on the same task.

Keep in mind that metaheuristics search for high-quality feasible solutions and Pareto approximations within a time budget rather than producing a mathematical proof of global optimality. For tractable linear or mixed-integer programs where an optimality certificate matters, use an exact solver workflow.
