# 第二版：以第一次访问的读者为准

读者需要依次知道：这是什么、是否适合自己的问题、操作起来怎样、能拿到什么、在哪里开始。读者不需要先理解平台的模块、方法数量、调用预算或部署架构。

| 第一版的问题 | 第二版的处理 |
| --- | --- |
| 首屏抽象口号，附带大量方法数量 | 用生产、排班、配送三个具体任务说明用途；移除数字装饰 |
| 深色官网里放浅色中文旧图 | 从独立演示工作台新采集深色中文、深色英文素材；语言与媒体一起切换 |
| 把 Git、Docker、模型参数作为大众用户主要路径 | 主体介绍问题、数据和方案；安装信息收进文档入口 |
| 「每一步都看得见」「一个结果是下一步的开始」等空泛标题 | 改成「直接描述目标和要求」「修改条件，比较新旧方案」「检查数据，再开始计算」等功能说明 |
| 多组静态图片重复占据主区域 | 首屏以可交互案例展示需求、计算和条件变化；实际工作台只保留一个可切换的大图区 |
| 混合真实截图与示意内容，却未形成稳定阅读关系 | 首屏明确标为交互示例；新截图区明确为工作台界面；数值来自有限示例的实际计算或真实求解器 |

正文只保留业务含义、用户操作和具体产物。团队署名保留 EIPI。不编造在线平台地址、客户、速度或效果提升。网站继续是可在 GitHub Pages 托管的静态站点。
