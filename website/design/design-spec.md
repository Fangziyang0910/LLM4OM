# LLM4OM promotional site

面向第一次接触优化建模的大众用户。首页用生产、排班、配送三个具体任务说明用途，让访客试着修改条件、查看方案和导出结果。正文只保留业务含义、操作和产物，不展示方法数量、调用消耗、技术架构或终端命令。页面署名 EIPI 团队，不增加未经提供的机构背书或客户案例。

使用中文和英文两套完整文案。首次进入默认中文；切换语言后同步导航、标题、说明、界面素材、交互示例、按钮、可访问性标签及页面元数据。语言偏好只在浏览器本地保存。保留无 JavaScript 时可读的中文主体。实际工作台截图重新采集为深色中文和深色英文两套。演示使用固定示例数据，不声称实时调用大模型。

视觉方向为现代深色官网。黑色与锌灰承托现有靛蓝品牌色，实际可行状态使用绿色。首屏以具体用途和完整的交互工作区建立视觉锚点，随后进入真实工作台大图、简洁功能说明和三步操作。Inter 延续现有品牌；中文使用系统字体。按 1440、1280、768、390、360、320 六种屏幕宽度检查。正文至少 14 像素，页签、按钮和大图对话框可键盘使用。

页面依次包含：核心用途与三场景交互演示；方案导出、条件比较和数据检查三个真实界面；需求整理、保留原方案、冲突诊断；三步使用方式；常见问题；开始使用入口和 EIPI 团队署名。生产演示允许改变资源和最低产量，排班允许指定员工日期，配送允许停用线路。每次变化均实际重新计算小型示例，并可下载当前结果。

动画直接表达操作：输入逐字出现、建模阶段推进、方案原位进入、产量条形过渡、排班人员在日期间移动、配送线路重绘、页面单次滚动显现。演示只自动播放一次，可以暂停、继续、重播或直接查看结果。离开视口或页面隐藏时暂停。减少动效设置下直接显示结果；不使用无限粒子、自动轮播或滚动劫持。

实现采用原生 HTML、CSS、JavaScript 模块和 Web Animations API，使用原生对话框和语义化组件。不增加框架构建、服务端、数据库或依赖。字体和图片随站点提供，无运行时 CDN。所有资源使用相对路径，兼容 GitHub Pages 的仓库子路径。仅把 website/public 的内容发布到 gh-pages，不发布设计记录、测试、平台运行数据或密钥。主项目公开由用户明确授权；本地未推送的平台提交不随宣传站发布。

设计判断：叙事角色是产品介绍；观看距离是手机或笔记本；视觉温度是清晰、有冲击力、可信；首屏只承担用途和主操作；视觉母题来自自然语言、约束、模型和实际方案的连续关系。现代感服务于把复杂决策变得可理解，而不是隐藏产品内容。

## Docs 扩展

用户要求把现有文档整理为完整中英文文档中心，并直接部署。首页通过持续可见的“文档 / Docs”入口与本地化指南链接进入；首页主体保持产品介绍。文档采用现有品牌色、字体和深色表面，桌面为侧栏、正文和页内目录三栏，小屏保留正文并使用原生目录对话框与折叠页内目录。阅读过程不使用大幅动画。

文档覆盖 46 个主题，每篇有中文、英文独立静态地址。双语切换保持同篇文章与对应章节，偏好与首页共用。全文搜索只加载当前语言的本地索引，支持快捷键、结果导航、无结果和加载失败后重试。文章含代码高亮与复制、滚动表格、来源、上一篇和下一篇。正文在禁用脚本时仍可阅读。

内容以当前 README、用户指南、方法文档、领域术语与代码为准；原始资料保持原位置，网站源稿是面向读者的双语整理。方法参数与覆盖范围由构建时读取的注册表校验。求解能力按库、原生接口、实际后端和许可分别说明，不把提示流程说成已部署训练权重或论文效果复现。
